# 食事ノート

公開ページ: https://hysyuk21-glitch.github.io/meal-note/

## セットアップ

写真・音声・文字で食事を記録し、Claude API で栄養を推定して Google スプレッドシートに保存します。

```
スマホの画面（index.html / GitHub Pages）
   │ 写真・文字・合言葉
   ▼
Google Apps Script（Code.gs）── Claude API（栄養の推定）
   │
   ▼
スプレッドシート「食事」シート
```

## 1. スプレッドシートと Apps Script

1. 新しい Google スプレッドシートを作る（血圧ノートと同じファイルでも OK）
2. 「拡張機能」→「Apps Script」を開き、このリポジトリの `gas/Code.gs` の中身を貼り付けて保存
3. 「プロジェクトの設定」→「スクリプト プロパティ」に次の2つを追加
   - `ANTHROPIC_API_KEY`：Claude Console で発行した API キー
4. エディタで関数 `setup` を選んで実行 → 権限を許可（「食事」シートができる）
5. `createUsers` の `names`（例：父・母・自分）を書き換えて実行 → 1人1つの合言葉ができ、実行ログに表示される
6. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - 表示された URL（`.../exec`）を控える

> コードを直したら「デプロイを管理」→ 編集 →「新バージョン」で更新しないと反映されません。

## 2. 画面

1. このリポジトリの GitHub Pages を有効にする（Settings → Pages → Branch: main / root）
2. 自分のスマホで `index.html` を開くと、設定がまだなので自動で `setup.html`（はじめの設定）に移ります
3. 「つなぎ先のアドレス」に Apps Script の URL、「合言葉」を入れて「確かめる」→「保存して始める」
4. ホーム画面に追加しておくとアプリのように使えます

### 家族の設定（リンクを送るだけ）

1. `setup.html` の「合言葉」に**送る相手の合言葉**を入れ、「家族に設定を送る」→「設定リンクを作る」
2. できたリンクを本人に LINE などで送る（1人ずつ）
3. 本人はリンクを開いて「この設定で始める」を押すだけ（「父 さんとして準備できました」のように表示）

### 人ごとの記録

- 合言葉で誰の記録かを見分け、シートの「記録者」列に名前を入れます
- 「今日の合計」や削除は本人の分だけが対象です
- スマホをなくしたときは `resetUserToken` で、その人の合言葉だけを作り直し、リンクを送り直します

設定は `#` 以降に入れているので、GitHub Pages のサーバーには送られません。ただしリンクに合言葉が含まれるので、本人以外には送らないでください。

### つなぎ先をコードに入れておく（任意）

`index.html` と `setup.html` の `FIXED_URL` に Apps Script の URL を入れておくと、設定ページでアドレスの入力欄が消え、設定リンクも合言葉だけになります。

## 3. 調整できるところ（Code.gs の CONFIG）

| 項目 | 内容 |
|---|---|
| `MODEL` | `claude-sonnet-5-5`（精度重視）／ `claude-haiku-5-5`（安さ重視） |
| `MAX_CALLS_PER_DAY` | 1日の API 呼び出し上限（使いすぎ防止） |
| `ENABLE_WEB_SEARCH` | 外食の公表値を Web で調べる。別料金。ツール名はドキュメントで確認してから有効に |

画面側の目安（`index.html` 冒頭）：`KCAL_GOAL`（1日のカロリー目安）、`SALT_GOAL`（塩分 7.5g）

## 注意

- 推定値です。特に塩分は見えない調味料が多く、ずれやすいです。
- 合言葉はブラウザに保存されます。家族以外に URL と合言葉を教えないでください。
- Claude Console で月の利用上限（Spend limit）も設定しておくと安心です。
